# AutoLoc

Multi-agency vehicle rental management platform (UP ASI, ESPRIT).

## Objectives
- Manage vehicles, agencies, reservations, and rentals
- Provide a REST API (Spring Boot) backed by MySQL
- Document the API with Swagger UI

## Stack
Java 17, Spring Boot, Spring Data JPA, MySQL, Maven, Lombok, Postman

## Actors
- *Client*: searches vehicles, makes and tracks reservations
- *Agent d'agence*: handles pickups, returns, and contracts
- *Responsable d'agence*: manages agency fleet and staff, monitors activity
- *Administrateur*: manages agencies, users, and global settings
